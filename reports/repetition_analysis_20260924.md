# 최신 raw 반복 분석 결과 — 2026-09-24

최신 `max_new_tokens8192_hakyung` 900개 응답에서 자동 반복 후보 **73건(8.11%)**을 찾았다. 원본·채점 정책·600/900 점수는 유지했고, 추가 API 호출과 재추론은 없다.

| 항목 | 반복 후보 73건 | 기준 미만 827건 |
|---|---:|---:|
| 정책 정답률 | 24/73 = **32.88%** | 576/827 = **69.65%** |
| 길이 상한 종료 | 67/73 = **91.78%** | 61/827 = **7.38%** |
| 답 추출 실패 | 20/73 = **27.40%** | 16/827 = **1.93%** |
| 생성 토큰 중앙값 | 8,192 | 398 |

반복 후보는 전체 추출 실패의 **20/36(55.56%)**, 전체 오답의 **49/300(16.33%)**를 차지했다. 응답 수로는 8.11%지만 생성 토큰은 **580,221/1,813,255(32.00%)**를 사용했다. 이는 관측된 토큰 사용 비중이며 반복 제거 시 절약할 수 있는 양의 추정은 아니다.

동일하게 length로 종료된 집단 안에서도 반복 후보의 정확도는 **20/67(29.85%)**, 기준 미만은 **26/61(42.62%)**였다. 정상 종료 반복 후보는 6건으로 작고, 이 중 4건이 정책상 정답이었다. 반복 후보를 일괄 오답이나 답 없음으로 처리하지 않는다.

## 측정 기준

긴 문장/행의 정확한 재등장 비율과, 짧은 구절·기호를 포착하는 공백 단위 16-gram 재등장 비율을 별도로 계산했다. 각각 최소 3회 등장해야 하며 첫 등장을 제외한 복제 분량을 센다. 둘 중 하나가 20% 이상이면 반복 후보로 표시했다. 문장 최소 길이·정규화·분모·겹침 처리 등 전체 정의는 [상세 보고서](../assignment/experiments/repetition_20260924/results/REPORT.md)에 있다.

기준을 10%·20%·30%로 바꾸면 후보는 각각 **91·73·64건**, 후보 정확도는 **35.16%·32.88%·31.25%**였다. 세 기준에서 모두 기준 미만 집단보다 정확도가 낮았다. 임계값은 사람의 오류 라벨로 최적화한 값이 아니다.

반복 후보의 반복 시작 위치 중앙값은 응답 문자 길이의 **23.32%**였다. 첫 25% 구간에서 39건, 25~50%에서 31건, 50~75%에서 3건이었다. 이는 나중에 3회 이상 반복되는 단위의 두 번째 등장 위치를 사후 측정한 값이다. 생성 토큰 위치·실시간 탐지 시점·영구 반복 진입 시점은 아니다.

## 발표에 사용할 해석

반복·응답 중단은 한 사례에 그치지 않고, 전체 응답의 일부에서 생성 분량과 답 추출 실패가 집중되는 패턴으로 확인됐다. 따라서 **반복을 줄이고 답을 확정하게 하는 학습안**을 비교 후보로 삼을 근거가 있다. 다만 이 분석은 모델 학습이나 반복 제거 실험이 아니며, 난이도·응답 길이·채점 오류의 영향을 분리하지 않았으므로 예상 성능 향상을 계산할 수는 없다.

문장 단위만으로는 기호나 짧은 구절 반복을 놓친다. 실제 `Computer_Science_16`, `Music_24`, `Music_27`은 긴 문장 반복률이 0%지만 16단위 반복 지표가 높았다. 자동 후보는 의미적 오류를 확정한 사람 라벨과 구분한다.
