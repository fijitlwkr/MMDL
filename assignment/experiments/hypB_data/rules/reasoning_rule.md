# 풀이 필요 기준

질문·정답·정리 풀이를 읽고, 정답에 이르는 데 필요한 최소 작업을 직접 판정한다.

| 판정 | 기준 |
|---|---|
| pass | 최소 한 단계의 추론이 필요하다: 계산, 여러 정보의 비교·결합, 조건·원리 적용, 그래프에서 읽은 값을 이용한 판단, 자료 해석, 보기들의 논리적 판별 |
| excluded | 단순 사실 회상 / 이름표·그림에서 위치·명칭만 찾기 / 그림·도표의 종류나 내용 묘사 / 영상 검사 종류만 식별 / 캡션 생성, 글자·표의 한 항목을 그대로 읽기 |
| borderline | 입력만으로 추론 필요성을 확신할 수 없음. 선별하지 않는다 |

- 객관식이라는 사실만으로 pass하지 않는다. 한 사실·이름표를 보기와 대응하는 문항은 excluded.
- 여러 값을 비교해 최고·최저를 정하는 문항은 실제로 여러 값의 비교가 필요하면 pass. 표에서 값 하나를 옮기는 것은 excluded.
- 풀이 길이·질문 패턴·기존 분야 라벨은 판정 근거로 쓰지 않는다.
- 자료와 정답이 충돌하는 문항은 선별하지 않는다.
- Art & Design 115건은 확보량이 적어 이 기준을 적용하지 않고 모두 포함했다.
