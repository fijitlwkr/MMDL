# 1단계 CPU 점검 · 2026-11-01

**수정한 기준값으로 8행 모두 통과.** ms-swift 3.12.3의 JSONL 로더와 train 모드 qwen3_vl 템플릿을 사용했다. 로컬 고정 revision processor, transformers 4.57.1, qwen-vl-utils 0.0.14, torch 2.8.0 CPU로 재실행했고 종료 코드는 0이다. 평가 시 생성용 프롬프트는 끝 토큰 `198`에서 끊긴다. ms-swift 기본 전처리를 사용했다.

각 칸은 수정 기준값과 실측이 일치한 토큰 수다.

이전 E1 기준값은 전체 대화를 한 번에 토큰화하면서 헤더 끝 줄바꿈과 응답 첫 줄바꿈 두 개를 `1406` 하나로 합친 결과였다. 사용자 지시에 따라 E1 4행의 전체·응답 수만 각각 +1로 수정했다. E2 4행과 나머지 필드는 이전 커밋과 동일함을 별도로 확인했다.

E1 4행 모두 평가용 프롬프트의 전체 ID가 ms-swift 입력의 프롬프트 부분과 일치하고, 끝 `198` 다음에 응답 첫 토큰 `271`이 이어진다. 프롬프트와 응답·종료 문자열을 따로 토큰화하여 연결한 기준 ID도 ms-swift 전체 입력과 일치한다.

E2 4행 모두 평가 processor의 전체 대화 토큰 ID가 ms-swift 전체 입력과 일치한다. 8행 모두 loss 마스크는 프롬프트 전체가 `-100`이고 응답 이후는 입력 ID와 일치한다.

고정 모델 구성으로 가중치 없이 모듈 이름을 대조했다. LoRA 정규식은 언어모델 36층 × 7개 projection에만 대응했다. seed 3407 순열은 3,000행을 중복 없이 포함하며 1161번 행은 320번째다. GPU에서 실제 학습 파라미터·VRAM·속도·병합·vLLM 로딩을 확인하는 것은 이후 단계다.
