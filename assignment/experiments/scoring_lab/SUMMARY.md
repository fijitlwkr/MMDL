# 채점 방식 실험 최종 정리 — H1·H2 단계

## 1. 결론과 팀 제안

**Qwen 규칙 파서를 기본으로 유지하고, 기존 Final Answer 100자 규칙으로 보완한 뒤 미추출·두 규칙 간 충돌·length 응답을 동일한 AI Judge에 보내는 하이브리드를 우선 채택안으로 제안한다.** 랜덤 폴백은 금지한다.

이번 결과는 해당 방식의 답 추출과 Judge 대상 감소를 뒷받침한다. 최종 HF baseline 점수 확정이나 평가 전체의 무오류 검증을 마친 것은 아니다. 확인된 기존 오독을 기록한 채 팀에서 프로토콜을 고정하고, 최종 입력에도 같은 검증을 적용해야 한다. 이번 정리 과정에서 파서 코드·Judge 설정·기존 응답·캐시는 변경하지 않았다.

## 2. 실험에서 확인한 것

| 확인 사항 | 결과 | 해석 |
|---|---|---|
| H1: Qwen–MMMU 공동 추출 성공군의 답 일치 | 267/316 = **84.49%** | 두 파서가 사실상 같은 답을 뽑는다고 가정하기 어렵다. |
| H1: 서로 다른 답을 낸 49건의 사용자 검토 | Qwen **47/49**, MMMU(no random) **2/49** 일치 | 이 불일치군에서는 Qwen이 원문의 최종 답을 더 잘 읽었다. 전체 파서 정확도의 비교는 아니다. |
| H2: Final Answer marker 자동 채택군 표본 | **100/100 일치**, 오류 0; Wilson 95% **96.30~100%** | 검토 표본에서 추가 규칙의 오독을 발견하지 않았다. 모집단 99% 이상을 보장하지 않는다. |
| H2: Qwen이 실패해 marker가 추가 채택한 군 | **59/59 일치** | 보완 규칙이 실제로 유효한 답을 추가 회수했다. |
| H2: 기존 Qwen도 성공했던 군 | **41/41 일치** | 같은 표본의 나머지 집단이다. |
| 전체 pilot의 Judge 대상 변화 | Qwen **503건 → hybrid 327건**, **176건(34.99%) 감소** | API 호출 대상 수 감소다. 실제 비용 35% 절감이나 최종 점수 개선을 측정한 값은 아니다. |

여기서 ‘일치’는 **사용자가 읽은 모델의 최종 답과 파서의 추출 답이 같음**을 뜻한다. 모델이 실제 문제를 맞혔는지의 GT 정답률과 구분한다. MMMU의 추출 실패가 더 적다는 이유만으로 MMMU 파서가 더 정확하다고 결론 내릴 수 없다.

H1 49건과 H2 100건에는 중복 10건이 있어, 검토한 고유 문항은 **139건**이다. 두 집단의 선정 방식과 목적이 다르므로 합쳐서 하나의 추출 정확도를 계산하지 않는다.

## 3. 권장 처리 흐름

아래는 이번 H1·H2에서 검토한 **객관식**의 기존 하이브리드 흐름이다. 주관식은 기존 별도 처리로 유지하며 이번 marker 검증의 범위에 포함하지 않는다.

| 순서 | 조건 | 처리 |
|---|---|---|
| 1 | `finish_reason=length` | **항상 공통 Judge**, 자동 채택하지 않음 |
| 2 | 정상 종료에서 Qwen과 유효 Final Answer 규칙이 서로 다른 답 반환 | 공통 Judge |
| 3 | 위 충돌이 없고 Qwen 규칙이 유효 답 반환 | Qwen 답 자동 채택 |
| 4 | Qwen이 실패하고 기존 Final Answer 규칙이 통과 | marker 답 자동 채택 |
| 5 | 두 규칙 모두 유효 답을 반환하지 못함 | 공통 Judge |

### Final Answer 100자 규칙의 정확한 의미

- 현재 정규식에 매치되고 실제 선택지에 해당하는 답 문자가 있어야 한다.
- 매치된 Final Answer 답 문자들이 모두 같아야 한다.
- **마지막 매치의 답 문자 부분이 끝난 위치부터 응답 끝까지 100자 이하**여야 한다. 출력 전체를 100자로 제한하거나 100토큰을 뜻하는 것이 아니다.
- 유효한 marker 답과 Qwen 답이 다르면 자동 채택하지 않는다.

이는 **우리 사용자 정의 규칙**이다. Qwen 공식 또는 MMMU 공식 규칙이라고 부르지 않는다. 의미적으로 모호한 모든 답을 판별하는 규칙도 아니다.

공통 Judge는 현재 설정한 `gpt-4.1-mini-2025-04-14`를 동일하게 사용한다. 비교 정책 간 동일 요청에는 캐시를 재사용한다. Judge가 Z 등 추출 실패로 완료한 경우 오답 처리하고 랜덤 답은 만들지 않는다. API 오류·미완료는 pending으로 구분하며 최종 점수 완료로 보고하지 않는다.

## 4. 남아 있는 한계

1. **현재 hybrid에도 실제 오독 1건이 남아 있다.** H1 `validation_Chemistry_18`의 원문 결론은 D인데 Qwen과 hybrid가 C를 채택했다. `Correct Answer: D`는 기존 Final Answer marker 범위에 들어가지 않아 H2 표본 모집단에도 포함되지 않았다.
2. 합성 반례 `Final Answer: A or B.`를 A로 읽을 수 있는 문제도 남아 있다. H2에서 오류가 없었다고 이 반례가 해결된 것은 아니다. 이를 보완하면 새 규칙 버전으로 분리하고 별도 자료에서 검증한다.
3. H2의 100/100은 marker 자동 채택 표본의 결과다. marker 없는 Qwen 자동 채택, 주관식, length, Judge 출력 전체의 정확성을 대신하지 않는다.
4. 라벨은 모두 사용자 `human_confirmed`, 검토자 yoonseok, `adjudicated=false`로 반환됐다. **단일 검토자 결과**이며 독립 2인 검증·조정은 미실시다. ID·원문 해시·근거 문장·유효 답·재사용 라벨 보존을 확인했다.
5. 자료는 기존 TSV 기반 출력 cap **9048**, 생성 seed **42**의 참고 실험이다. 원본 900건에서 선택지 입력 오류 1건을 격리해 **899건**을 비교했다. H2 표본 추출 seed 3407과 생성 seed 42를 혼동하지 않는다. 팀 최종 **HF 고정 revision·seed 3407·validation 900건**의 결과로 옮겨 적지 않는다.

## 5. 완료와 남은 작업

| 항목 | 현재 상태 |
|---|---|
| H1 파서 불일치 검토 | 단일 검토자 49건 반환·검증·집계 완료 |
| H2 Final Answer 자동 채택 검토 | 단일 검토자 표본 100건 반환·검증·집계 완료 |
| H3 length 처리 | 기존 pilot의 규칙 진단은 있음. length 115건(MC 107/open 8). 전체 Judge 처리와 종합 검증 완료는 아님. **length 항상 Judge 방침 유지** |
| H4 cap 영향과 채점 방식 영향 비교 | 같은 조건의 HF 전량 cap 2개 이상 필요. 현재 자료로 공식 격차의 주원인이나 최적 cap을 확정하지 않음 |
| VLMEvalKit | 중간 실험에서 추가 비교 필요성이 없어 후보에서 제외(탈락). 기존 비교 결과·코드는 근거로 보존 |
| 최종 baseline | 팀 프로토콜 고정 후 HF 전량 raw에 적용·검증·채점 필요. 이번 H1/H2로 점수까지 확정하지 않음 |

H1의 ‘대부분’, H2의 X=99%는 사전 확정된 기준이 아닌 제안값이었다. 관측 결과를 기록하되 사전 등록된 가설의 통계적 지지·기각으로 소급 포장하지 않는다. AI Judge 자체의 육안 정확성 검증은 합의한 작업 범위에서 제외한다.

## 6. 팀 공유용 요약

> 기존 저장 응답으로 채점 방식의 답 추출을 비교했습니다. Qwen과 MMMU의 공동 추출 성공군 일치율은 84.49%였고, 불일치 49건의 단일 검토자 판정에서는 Qwen 47건, MMMU 2건이 원문의 최종 답과 일치했습니다. Qwen에 Final Answer 규칙을 더한 자동 채택군의 무작위 표본 100건은 전부 검토 답과 일치했으며, Qwen이 실패한 추가 채택 59건도 모두 일치했습니다. 기존 899건 pilot에서 Judge 대상은 503건에서 327건으로 약 35% 감소했습니다. 따라서 Qwen 기반 하이브리드를 우선 채택안으로 제안하되, 확인된 marker 외 오독과 표본 검증의 한계를 명시하고 length 항상 Judge·랜덤 폴백 금지를 유지하겠습니다. 이는 legacy-pilot 결과이며 최종 HF baseline 점수는 별도 검증이 필요합니다.
