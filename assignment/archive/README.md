# archive

baseline 확정 전 팀원별 개인 작업 공간(hakyung, jinho, sungjun, yoonseok)을 원형 그대로 보관한다.

- 유지보수하지 않는다. 코드는 `code/`, `results/`, `assignment/experiments/` 어디에서도 import하거나 실행 의존성으로 참조하지 않는다. 각 실험의 결과 문서(`*/outputs/*.md`)는 [실험 목차](../experiments/README.md#개인-탐색-실험-참고용)에서 baseline 보고서의 근거로 인용한다.
- 스크립트 일부는 RunPod의 `/workspace`를 기본 경로로 가정한다. 출력 JSON·로그에 남은 절대경로는 실행 당시의 기록이므로 수정하지 않았다.
- 각 폴더의 내부 경로는 자기 파일 위치 기준이라, 폴더 단위로 옮겨도 폴더 안의 상대 구조는 유지된다.
