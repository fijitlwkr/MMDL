# assignment — baseline 과제 전용 (동결)

**Qwen3-VL-4B-Instruct MMMU-val baseline 평가 과제(2026-09, 마감 9/28)의 근거 자료다. fine-tuning 작업은 여기에 추가하지 않는다.**

| 폴더·파일 | 내용 |
|---|---|
| [`experiments/`](experiments/README.md) | baseline 채점 방식 선택, 격차 분석 실험과 재현 도구 |
| `runs/` | 최종본이 아닌 baseline 추론 run(draft, 2048 등). 최종본은 [`results/mmmu_team_baseline/`](../results/mmmu_team_baseline/README.md) |
| [`archive/`](archive/README.md) | 팀원 개인 작업 공간 원형 보관. 참조 금지 |

fine-tuning 이후에도 계속 쓰는 것은 다음 세 곳이다.

- 평가 코드: [`code/`](../code/)
- 결과: `results/<실행 이름>/`
- 보고서: `reports/`
